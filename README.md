# Dynamic Color Clock

A simple digital clock built with React, Vite, and `date-fns` that displays the current date and time and changes color every second.

## How to Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Open the local URL shown in your terminal (usually `http://localhost:5173`) in your browser.
